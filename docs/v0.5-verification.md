# v0.5 differential research — verification

Date: 2026-10-04. Scope: MASTER-PLAN section 69, baseline versus stimulus

## Implementation and methodology

- Adds optional typed `behavioralComparison` to case exports, methodology 1.0,
  six category reports and complete/partial/unavailable states.
- Reuses the existing independently loaded fresh browser contexts in one shared
  sandbox: passive baseline, then bounded agent stimulus. One sequential pair;
  no randomized repetition, causal proof or performance benchmark is claimed.
- Network compares type/method/canonical URL/status/failure and occurrence counts.
  Navigation compares recorded successful navigation events; blocked attempts
  remain separate evidence. Primary browser archive records avoid stream overlap.
- Final DOM is now separately captured and timestamped after agent execution,
  using the existing form removal/redaction and byte cap. DOM digests/byte counts
  compare the sanitized evidence delivered in the export, not hostile markup rendering.
- Process compares command identity and multiplicity, ignoring PID churn. Socket
  compares established protocol/remote endpoint identity and multiplicity, ignoring
  local ephemeral ports. Both use timestamped whole-sandbox snapshots and explicit
  provider availability, including ambient activity; no action attribution is claimed.
- Timing compares elapsed first-to-last browser event spans, including waits between
  actions. It does not measure model latency or page response latency; unequal windows
  are not normalized.
- Reports include added, baseline-only, changed-count and unchanged identities,
  evidence links, snapshot JSON paths and limitations. Output caps: 40 differences,
  12 references per difference; aggregate totals retain all compared identities.
- Unavailable collectors/missing pairs/older untimestamped DOM are explicit.
  Partial runs or collection limits cannot establish absent behaviour.
- Public controlled demo parameters, policy, sandbox limits and internal-route gates
  remain the existing boundaries. No new user-controlled tools or commands were added.
