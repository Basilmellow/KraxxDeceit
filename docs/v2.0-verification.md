# v2.0 PDF and bundle verification

Date: 2026-10-04. Scope selected by the user: PDF reports and sharing-ready exports.

## Implementation

Client-only lazy-loaded PDF and ZIP generation using pinned pdf-lib 1.17.1 and
fflate 0.8.3. No case upload, target/asset retrieval, investigation request or model call.
PDF contains inert text with numbered A4 pages. Non-ASCII characters use literal
Unicode code point escapes; JSON and Markdown preserve the original Unicode.
Reports reject more than 100,000 Markdown characters or 40 PDF pages visibly.
Both formats revalidate the 3 MiB case and reject digest mismatches. Raw worker logs
are discarded. Legacy cases without digests are labeled; matching digests do not
authenticate the source. Exports are not automatically anonymized.

ZIP entries are fixed: case.json, report.pdf, report.md, README.txt, SHA256SUMS.txt.
Checksums cover exact file bytes and are separate from the normalized case digest.
JSON retains complete recorded evidence; summaries include provenance, hypothesis
references, comparison limitations, research iterations and assessment origins.
